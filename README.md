# Xander — Personal Website

Personal portfolio website created for **CCC 110 – Introduction to Information and Communication Technology**.

## Technologies

- HTML
- CSS
- JavaScript
- Git / GitHub

## Features

- Responsive personal portfolio layout based on the Figma homepage design
- Smooth navigation to About, Skills, Projects, and Contact sections
- Selected creative project cards
- Responsive mobile navigation
- Demo contact form with HTML validation and JavaScript confirmation
- Accessible semantic structure, labels, alt text, and visible keyboard focus

## Run locally

Open `index.html` directly in a browser or use the VS Code **Live Server** extension.

## Note

The contact form is a front-end demonstration only and does not send email or store messages on a server.
